STANDALONE CV DEMO
FOR LAPTOP & JETSON.

Complete offline computer vision and edge loss prevention suite for unattended commercial coolers. Connect your built-in laptop webcam or USB camera, enroll custom shelf SKUs in 3 seconds, and test sub-15ms extraction detection in real-time.

OFFICIAL RELEASE • V1.4.2

NEX VISION CORE DEMO

Includes the autonomous CV detector engine, local FastAPI event server, real-time bounding box visualizer, and 3-second SKU enrollment tool.

Download Demo Package (.ZIP)
PACKAGE: nex_vision_demo
SIZE: ~30 MB (Full Offline Package)
PLATFORM: macOS / Win / Linux
RUNTIME: Python 3.10+
01

DOWNLOAD & UNPACK ARCHIVE

Click the download button to grab the standalone distribution archive, then unpack it into any working directory on your computer:

unzip nex_demo_standalone.zip -d nex_demo && cd nex_demo TERMINAL
02

EXECUTE AUTOMATED RUNNER

Execute the automated launch script. It provisions an isolated Python environment and installs all lightweight vision dependencies:

./start_nex.sh MACOS / LINUX
start_nex.bat WINDOWS
03

LOCAL OFFLINE TELEMETRY

When launched offline on your laptop via the script above, the packaged server runs completely locally and serves your video stream with bounding boxes at:

http://localhost:8000/dashboard OFFLINE LOCALHOST
04

TEST & ENROLL CUSTOM SKUS

Hold any beverage, snack, or retail product toward your webcam and click «Add New SKU». The contour engine indexes its geometry in 3 seconds, immediately identifying shelf extractions with real-time bounding boxes.
